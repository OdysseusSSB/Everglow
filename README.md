You will need Packwiz installed for building from the source or contributing. To build, clone the repo to your computer and in the root folder run "packwiz modrinth export" which will generate a .mrpack file within the folder. Any compatible launcher (Modrinth, Prism etc.).

To contribute, files aside from mods can be dragged into the respective file locations in the repo. To manage mods, use packwiz on the root folder. "packwiz modrinth add" is the command for adding mods. Always run "packwiz refresh" before pushing.
